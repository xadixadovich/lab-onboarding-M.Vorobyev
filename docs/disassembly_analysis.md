# Анализ ассемблерного кода (x86-64, AT&T)

## Разбор по инструкциям

- `-4(%rbp)` - локальная переменная-аккумулятор (`sum`), начальное значение 0.
- `-8(%rbp)` - локальная переменная-счетчик (`i`), начальное значение 1.
- `jmp .L2` - сначала переход к проверке условия (цикл с предусловием).
- `.L2: cmpl $10, -8(%rbp)` / `jle .L3` - пока `i <= 10`, идти в тело цикла.
- `.L3` (тело): `eax = i; sum += eax; i += 1`.
- После выхода из цикла `movl -4(%rbp), %eax` кладет `sum` в `eax`,
  то есть это возвращаемое значение функции.

## Эквивалентный код

Python:

```python
def calc():
    total = 0
    i = 1
    while i <= 10:
        total += i
        i += 1
    return total
```

C:

```c
int sum = 0;
for (int i = 1; i <= 10; i++) {
    sum += i;
}
return sum;
```

Функция вычисляет сумму чисел от 1 до 10. Результат: 55.
