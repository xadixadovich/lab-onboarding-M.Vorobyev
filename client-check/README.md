# Практическая работа 9 — аудит клиентского компьютера

## Файлы
- pc_info.bat — основной запускной файл, содержит подпрограмму :log.
- pc_info.ps1 — сбор характеристик компьютера, чтение списка ПО из реестра и анализ категорий.
- pc_report.txt — автоматически формируемый отчёт после запуска.
- screenshot_audit.pn` — скриншот консоли после выполнения (добавляется вручную).

## Базовые категории ПО
- Офисный пакет: Office, LibreOffice, OpenOffice, МойОфис.
- Браузер: Chrome, Firefox, Edge, Яндекс.Браузер.
- PDF: Acrobat, Foxit, SumatraPDF.
- Архиватор: 7-Zip, WinRAR, WinZip.
- Антивирус: Defender, Kaspersky, ESET, Dr.Web.

## Признаки ПО для дополнительной проверки
Игровые платформы и игры; торрент-клиенты; мессенджеры; программы для развлечений и оформления рабочего стола. Наличие таких программ означает только необходимость проверки администратором, а не автоматическое удаление.

## Запуск
Поместить pc_info.bat и pc_info.ps1 в одну папку и запустить pc_info.bat. Отчёт будет создан рядом с файлами. Используется Get-CimInstance, поэтому скрипт не зависит от устаревшей wmic.

## Проверка логики
Для тестирования предусмотрен необязательный режим через переменную окружения PC_AUDIT_TEST_APPS. Если она указывает на текстовый файл, содержащий по одному названию программы на строку, анализ выполняется по этому тестовому списку вместо фактического списка реестра.

Пример проверки:
powershell
$env:PC_AUDIT_TEST_APPS = "$PWD\tests\test_apps_missing_and_flagged.txt"
.\pc_info.bat
Remove-Item Env:PC_AUDIT_TEST_APPS

Затем повторить с tests\test_apps_complete.txt. В первом списке намеренно отсутствует часть базового ПО и присутствуют признаки избыточного ПО; во втором базовые категории представлены, а признаки избыточного ПО отсутствуют.

## Ограничения
- Анализируются названия приложений в реестре, а не дата последнего запуска.
- Некоторые приложения могут отсутствовать в реестре или иметь нестандартные названия.
- Поиск антивируса по названию не заменяет проверку состояния защиты Windows.
- Edge может быть компонентом Windows.
- Результаты являются рекомендациями для администратора. Удаление программ не выполняется.
